Part 1 · The Hermes incident

We gave an AI the keys.
Here's what it did with them.

We ran one of the popular open-source AI agents on GeneralDussDuss's machine (the Dussmeister, to his friends; Dussy, to his enemies), with the best model money can buy. It was supposed to build things on its own. Instead he spent hours babysitting it. Not because the AI was dumb. Because the cage around it was made of paper.

I

It got stuck in a loop and couldn't get out

Try something. Fail. Try the exact same thing. Fail. Again. Again. Every failed attempt stayed in its memory, so it kept talking itself into the same mistake.

Plain English
A Roomba bumping the same chair leg for an hour. The only fix was unplugging it and starting over by hand.

II

It kept reaching for tools that were switched off

The browser tools were disabled. The AI didn't know. It kept trying to use them, got nothing back, and tried again. Silently.

Plain English
Flipping a light switch that isn't wired to anything, forever, with nobody telling it the switch is dead.

III

Its only safety rule was a polite note

"Please confirm before doing anything irreversible" lived in a text file the AI reads at startup. A suggestion, not a lock. When the conversation got long, the suggestion got trimmed out.

Plain English
A sticky note on the fridge that says "don't eat the cake." Works until it doesn't.

IV

It kept the passwords in a plain text file next to itself

API keys and login tokens sat in a readable file in the same folder the AI could browse. Nothing stopped it reading or leaking them.

Plain English
The house keys taped to the front door.

V

It made things up, got caught, and doubled down

It would state a fact, a file path, a config value, a reason a build failed, with total confidence. GeneralDussDuss would check. It was wrong. He'd say so. And instead of re-checking, it would restate the wrong thing with more confidence, sometimes inventing a reason why he was the one mistaken. Numerous times. Hours of it.

Plain English
A contractor who tells you the wall is load-bearing, gets shown the blueprints, and says the blueprints are wrong. The problem isn't the one mistake. It's that nothing in the system made it go look.
